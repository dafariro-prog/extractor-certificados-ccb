Cómo funciona. El PDF se lee en tu navegador con pdf.js; el texto del certificado se envía a la API de Anthropic con tu propia clave, se extrae aplicando las 68 reglas de PROMPT_FINAL.md, se audita contra el mismo texto y se normaliza a la estructura canónica exacta. El PDF nunca se sube a ningún servidor propio: no existe backend.
Tu clave. Se guarda solo en el almacenamiento local de este navegador y viaja únicamente a api.anthropic.com. Usa una clave dedicada con límite de gasto.
Modo borrador. Sin clave, la herramienta aplica un parser local de expresiones regulares: sirve para inspeccionar rápido, no produce el JSON canónico completo y no debe cargarse al S3.
